## 1. 產品概述

### 1.1 產品目標
開發一個**生產環境可用**的 YouTube 頻道自動轉錄工具，能夠：
- 穩定追蹤多個 YouTube 頻道的新影片
- 使用 Whisper AI 將影片音訊轉錄為文字稿
- 在長時間運行（數小時）中斷後能安全恢復
- 提供清晰的進度顯示和錯誤處理

### 1.2 目標用戶
- 需要追蹤特定 YouTube 頻道內容的研究者
- 希望將影片內容轉為文字閱讀的用戶
- 需要批量處理影片的內容創作者

### 1.3 非目標
- 不支援並行處理（資源限制）
- 不支援分散式部署（單機工具）
- 不追求極致效能（Reliability > Performance）

## 2. 功能需求

### 2.1 核心功能 (P0 - 必須實現)

#### FR-001: 頻道追蹤
- 從 YAML 配置檔讀取頻道列表
- 每個頻道可單獨設定語言、最大影片長度
- 支援使用 cookies 解鎖會員專屬/年齡限制內容

#### FR-002: 影片下載
- 使用 yt-dlp 下載音訊（mp3）
- 自動過濾超過設定時長的影片
- 支援中斷後續傳（yt-dlp 內建支援）

#### FR-003: 語音轉錄
- 使用 Whisper 模型進行轉錄
- 支援多種 Whisper 實現（openai-whisper, whisper.cpp, faster-whisper）
- 可選擇模型大小（tiny/base/small/medium/large）

#### FR-004: 文字稿輸出
- Markdown 格式輸出
- 包含影片metadata（標題、發布日期、時長、字數）
- 時間戳標記（[00:00] [01:30] ...）
- 按頻道和年月組織檔案結構

#### FR-005: 斷點續傳
- 程式中斷後重新啟動，自動跳過已處理影片
- 支援「影片級」檢查點（每部影片處理完儲存）
- **關鍵要求**：斷電不丟失進度

#### FR-006: 狀態管理
- 使用 SQLite 記錄處理狀態
- 自動清理超過 7 天或超過 100 筆的舊記錄
- 記錄處理時間、錯誤類型、重試次數

### 2.2 重要功能 (P1 - 應該實現)

#### FR-007: 進度顯示
- 實時顯示當前處理進度
- 顯示頻道進度（3/10 頻道）
- 顯示影片進度（5/20 影片）
- 預估剩餘時間

#### FR-008: 智能錯誤處理
- 區分不同類型錯誤：
  - 網路問題（立即重試）
  - Rate limit（延遲重試）
  - 資源不足（換小模型重試）
  - 影片問題（永久跳過）
  - 系統問題（終止程式）
- 自動重試機制（指數退避）

#### FR-009: 測試模式
- `--dry-run` 參數：只檢查不實際下載/轉錄
- 驗證配置正確性
- 顯示會處理哪些影片

#### FR-010: 詳細日誌
- 頻道級錯誤日誌
- 結構化日誌輸出（JSON）
- 處理統計摘要

### 2.3 次要功能 (P2 - 可以實現)

#### FR-011: 配置驗證
- 啟動時驗證 YAML 配置
- 檢查必要依賴（ffmpeg, yt-dlp, whisper）
- 驗證模型名稱、語言代碼

#### FR-012: 統計報告
- 生成處理報告（成功/失敗/跳過數量）
- 平均處理時間統計
- 錯誤類型分布

## 3. 非功能需求

### 3.1 可靠性 (Reliability)

| 需求 ID | 描述 | 驗收標準 |
|---------|------|----------|
| NFR-001 | 斷電安全 | 處理 10 部影片，在第 5 部時強制斷電，重啟後第 1-4 部不重新處理 |
| NFR-002 | 錯誤隔離 | 單一影片處理失敗不影響其他影片繼續處理 |
| NFR-003 | 資料完整性 | SQLite 資料庫損壞時能自動恢復或重置 |
| NFR-004 | 磁碟空間 | 磁碟空間不足時優雅退出並提示用戶 |

### 3.2 可用性 (Usability)

| 需求 ID | 描述 | 驗收標準 |
|---------|------|----------|
| NFR-005 | 進度可見 | 用戶能隨時看到「現在處理哪部影片」「還剩多久」 |
| NFR-006 | 錯誤清晰 | 錯誤訊息包含：什麼錯、為什麼錯、怎麼辦 |
| NFR-007 | 配置簡單 | 最少只需設定頻道 URL 即可運行 |

### 3.3 效能 (Performance)

| 需求 ID | 描述 | 驗收標準 |
|---------|------|----------|
| NFR-008 | 狀態查詢 | 查詢影片是否已處理 < 10ms（SQLite 索引） |
| NFR-009 | 記憶體使用 | 處理長影片（2小時）時記憶體使用 < 8GB |
| NFR-010 | 啟動速度 | 從執行到開始處理第一個影片 < 30 秒 |

### 3.4 可維護性 (Maintainability)

| 需求 ID | 描述 | 驗收標準 |
|---------|------|----------|
| NFR-011 | 模組化 | 每個模組可獨立測試，不依賴其他模組的具體實現 |
| NFR-012 | 類型安全 | 所有函數使用 Type Hints，通過 mypy 檢查 |
| NFR-013 | 測試覆蓋 | 核心邏輯測試覆蓋率 > 80% |

## 4. 系統限制

### 4.1 技術限制
- **單線程處理**：Whisper 已吃滿資源，不考慮並行
- **本機運行**：不支援雲端/分散式部署
- **SQLite 限制**：單機資料庫，不支援多用戶同時寫入

### 4.2 業務限制
- **YouTube 限制**：受 yt-dlp 和 YouTube 反爬蟲機制限制
- **版權內容**：無法下載/轉錄受版權保護的內容
- **資源需求**： Whisper large 模型需要 ~10GB 記憶體

## 5. 使用者介面

### 5.1 CLI 介面

```bash
# 基本使用
youtube-transcriber --config channels.yaml

# 測試模式
youtube-transcriber --config channels.yaml --dry-run

# 詳細輸出
youtube-transcriber --config channels.yaml --verbose

# 指定輸出目錄
youtube-transcriber --config channels.yaml --output ./transcripts

# 顯示版本
youtube-transcriber --version
```

### 5.2 配置檔格式 (channels.yaml)

```yaml
# 輸出設定
output:
  base_dir: "./output"

# Whisper 設定
whisper:
  backend: "cpp"  # openai, cpp, faster-whisper
  model: "medium"
  language: "auto"

# 處理設定
global:
  max_videos_check: 5      # 每個頻道檢查最新 N 部
  max_duration: 90         # 最大影片長度（分鐘）
  cookies_file: null       # 可選的 cookies 檔案路徑

# 頻道列表
channels:
  - name: "老高與小茉"
    url: "https://www.youtube.com/@laogao"
    language: "zh"         # 可選，覆寫全域設定
    max_duration: 120      # 可選，覆寫全域設定
  
  - name: "TechLead"
    url: "https://www.youtube.com/@TechLead"
    language: "en"
```

### 5.3 輸出格式

#### 檔案結構
```
output/
├── {channel_name}/
│   └── {YYYY-MM}/
│       └── {YYYY-MM-DD}_{video_id}_{title_slug}.md
├── temp/                    # 暫存音訊檔（處理完自動清理）
└── logs/                    # 錯誤日誌
    └── {channel_name}_errors.log
```

#### Markdown 格式
```markdown
---
channel: "老高與小茉"
video_id: "abc123xyz"
title: "這是影片標題"
published_at: "2026-01-15"
duration: "45:30"
word_count: 5420
---

# 這是影片標題

[00:00] 大家好，歡迎來到我的頻道...
[01:30] 今天我們要聊的是...
[03:45] 首先我們來看看...
...
```

## 6. 驗收標準

### 6.1 功能驗收

| 測試項目 | 測試步驟 | 預期結果 |
|---------|---------|----------|
| 基本流程 | 配置 1 個頻道，執行程式 | 成功下載、轉錄、輸出 Markdown |
| 斷點續傳 | 處理 5 部影片時強制中斷，重啟 | 第 1-4 部顯示「已處理」，從第 5 部繼續 |

|---------|---------|----------|
| 長時間運行 | 連續處理 50 部影片 | 不崩潰、記憶體使用穩定 |
| 中斷恢復 | 隨機中斷 10 次 | 每次都能正確恢復，無重複處理 |

## 7. 風險與緩解

| 風險 | 可能性 | 影響 | 緩解措施 |
|------|--------|------|----------|
| YouTube 封鎖 IP | 中 | 高 | 支援 cookies、rate limit 處理、用戶提示 |
| Whisper 模型載入失敗 | 低 | 高 | 啟動時檢查、清晰的錯誤訊息 |
| 磁碟空間不足 | 中 | 中 | 啟動時檢查、處理中監控 |
| SQLite 資料庫損壞 | 低 | 高 | 自動備份、損壞檢測、自動重建 |
