# Claude Cowork setup: the only 2 files you need

[00:00] I've built an entire AI Second Brain in Cloud Cowork, and the entire thing runs on just two text files. First, you'll want to create a Cowork OS folder, then create an empty text document, name it Claud.md, and save it as a markdown document within your Cowork OS folder. Put simply, the Claud.md file is the instruction manual that Cowork reads at the start of every session. For example, in my Claud.md, there's a routing map here that tells Cowork to pull up my travel workstation whenever I start planning a trip. Then, create another empty document, name it memory.md, and save it as a markdown document in the same folder. The memory.md file stores your active projects and decisions you've made, so it remembers critical information between sessions.
[00:42] For example, when I plan a trip to Taiwan, Cowork first reads my travel workstation, Claud, and memory files, then reminds me to fill out a specific visa application because I remember I had to do that last time. I've created Claud.md and memory.md templates that you can copy and use immediately.
