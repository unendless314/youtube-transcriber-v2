# Activate ChatGPT with iPhone’s Action Button

[00:00] Here's how I map my iPhone's action button to instantly launch ChatGPT.
[00:03] Doing this eliminates decision fatigue, so now I use AI for tasks I would have skipped before.
[00:09] The setup is simple. Go to settings and search for the action button, then scroll all the way to shortcuts, search for ChatGPT, but instead of starting a new chat, choose start dictation. This way I can talk to ChatGPT when I'm out and about, plus I can edit before sending. Pro tip, since I still want quick access to do not disturb, I've mapped that action to a backtap instead. So this takes a bit more effort. You have to first create a shortcut to toggle do not disturb. Feel free to take a screenshot and copy the setup.
[00:41] Then search for backtap, set double tap to the shortcut we just created, toggle do not disturb, and that's it.
