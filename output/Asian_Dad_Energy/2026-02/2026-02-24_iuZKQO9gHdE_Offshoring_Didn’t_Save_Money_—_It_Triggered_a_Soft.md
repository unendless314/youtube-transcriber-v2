# Offshoring Didn’t Save Money — It Triggered a Software Collapse #layoffs #softwareengineer #tech

[00:00] As a consultant, I had the good luck of working through the code bases produced by many offshore vendors. These were dumpster fires of code bases. Now we're talking about horrific mountains of copy and paste spaghetti code. Code that seemed to have been created without any thought of long term maintainability. Code that often had little or sometimes no documentation at all. There seems to be almost no attention paid to the long term extensibility or reusability of the code. Sometimes I saw code that was barely functional. Code that seems to have more bugs than actual functionality.
[00:39] And such code bases resulted in applications that were barely functioning. And oftentimes when I worked with offshore support teams and offshore software engineers, it seemed to me that those engineers really didn't fully understand the code base.
